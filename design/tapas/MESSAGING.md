# Tapas · Product messaging

## Product promise

**Capture on your Mac. Keep your files. Build whatever comes next.**

Tapas turns your words into readable local files. Use them with your favorite
coding agent, write a script, or build your own agent harness. Any tool that can
read files can work with your data.

**Your files are the interface.**

## Brand and placement

- **Brand line:** Small tools. Good company.
- **Product headline:** Capture on your Mac. Keep your files. Build whatever comes next.
- **Guiding principle:** Your files are the interface.

Keep the brand line with the Tapas name and pintxo. Use the product headline and
supporting paragraph to introduce what Tapas enables. Use the guiding principle
when explaining files, extensibility and user control.

The headline deliberately leaves room for people to build their own workflows.
An agent can be one consumer of the files; scripts, editors and tools we have
never anticipated belong equally in this story. Specific agents can appear as
examples without defining the product's boundary.

A download action needs a published, usable release. While signing and

## The principle behind the copy

Files come first; integrations are optional conveniences. Reading and using a
saved transcript must not depend on a Tapas account, proprietary API, export
operation, or MCP server. A future MCP integration could make access easier,
while the underlying files remain directly usable.

The user chooses which agents or scripts can access the files and where their
analysis runs. Tapas captures locally; a user-chosen cloud agent has its own data
handling. Derived analysis should preserve the source material.

Explain these properties directly. The message should stand on what Tapas makes
possible, without unverified claims about competitors or blanket claims that
MCP integrations prevent data ownership.

## Demonstrate it

Show one concrete sequence: capture a thought → open the saved Markdown → use a
script or coding agent to build on it. Keep the file visible so the connection
is clear. The agent's analysis is performed by the user's chosen tool.

Use Dictado for the current preview. Acta remains in development. Label any
scripted demonstration as such; do not imply that native MCP access, live file
streaming, or meeting capture already exists.

The current native preview saves history when enabled and automatically redacts
that copy. Preserving the full finished transcript by default is a pending
product decision. This messaging change does not change that behavior or
promise that the stored copy is an unmodified transcript.

## Community and attribution

Give Desert Ant and the model ecosystem visible credit. Describe the app's own
license and each dependency's terms separately. The repository is public, but
Tapas does not yet have an open-source license; applying one remains a separate
decision. Avoid describing the entire model stack as unrestricted open source.
