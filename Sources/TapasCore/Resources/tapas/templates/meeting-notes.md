# Meeting notes

Use for an Acta meeting recap, including long meetings. Keep the source language
unless asked otherwise. The section guidance describes what to write; do not
copy it into the result.

## Summary
Explain the purpose and outcome in a short paragraph.

## Action items
Make follow-up easy to scan. Use one checkbox per concrete agreed task, with a
stated deadline when available and a supporting source citation. If no deadline
was stated, omit it. An unchecked box means completion has not been established.
Group items as below; do not invent individual identities for other participants.
If a group has no supported items, say “None recorded.”

### You
Tasks the user explicitly accepted or was clearly assigned. Use conversation
context or user-provided speaker context to establish ownership.

### Others
Tasks accepted by or clearly assigned to other participants, kept in one group.
Individual names are optional only when explicitly supported; named attribution
is not needed for an item to be useful.

### Unclear owner
Agreed tasks whose ownership cannot be established. Do not guess between You and
Others. Omit this group when there are no such items.

## Decisions
List confirmed decisions separately from proposals, with source citations.

## Open questions
List unresolved questions and dependencies. Keep suggested or unaccepted work
here rather than presenting it as an agreed action item.
