# Develop an idea

Use when asked to assemble related dictations or meeting passages into a coherent
brief. Resolve the idea from the request or named recording; ask for the topic if
it cannot be identified. Search related terms across Dictado and Acta, expanding
the period when useful. State the sources and time span used.

Read matching passages and follow the idea's evolution. Distinguish the user's
own dictations from unattributed meeting statements. Preserve alternatives,
contradictions, and changes of mind; a newer mention is not automatically a final
decision. Cite the evidence supporting the brief.

Produce a brief covering the problem, intended audience, proposed approach,
constraints, alternatives, and open questions. Use a user-selected template when
provided. Mark missing details as unknown. Put your proposed experiments or next
steps in a separate suggestions section so they cannot be mistaken for recorded
intent. Do not invent market validation or silently resolve competing directions.

Return the brief in the conversation. If asked to save, use a descriptive new
Markdown file under `outputs/` or the user's destination. Preserve the source
recordings and existing briefs unless revising a specific brief was requested.
