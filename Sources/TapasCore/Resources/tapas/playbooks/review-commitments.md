# Review my commitments

Use when asked what the user said they would do or which recorded commitments
may still need attention. Use the requested period, or the last 30 days if
unspecified; state dates, coverage, and sources reviewed.

Find explicit commitments in Dictado and relevant Acta passages. Distinguish firm
commitments from wishes, suggestions, hypothetical examples, and tasks assigned
to someone else. Audio-source labels do not identify a speaker: include an Acta
commitment as the user's only when attribution is supported by the conversation
or supplied context. List uncertain ownership separately.

For each commitment, report the task, supported owner, stated deadline, original
source, and any later status evidence. Search later accessible recordings for
completion, cancellation, or changed plans; no later mention means status unknown.
Merge repeated mentions of the same task without merging distinct deliverables.
Resolve relative deadlines only when the recording date and context support it;
otherwise preserve the wording and uncertainty. Call an item overdue only when
both its deadline and open status are supported.

Return a sourced commitments table, separating confirmed open/completed/cancelled
items from unknown status and ownership. Save a separate Markdown report under
`outputs/` if requested. Reviewing commitments does not itself create tasks,
reminders, calendar events, or messages.
