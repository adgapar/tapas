# Polish a dictation

Use when asked to clean up saved dictation. Read the requested take and preserve
its language, meaning, names, numbers, uncertainty, and redaction markers.
Remove fillers and repetition, fix punctuation, and add paragraph or list breaks
where helpful. Follow an explicitly requested style or template. More substantive
rewriting is appropriate only when requested; do not add facts or commitments.

Return the polished text without modifying the original recording. Save a separate
Markdown document under `outputs/` only when asked, or use the user's destination.
Do not paste into another application unless requested. Saved Dictado history is
redacted and cannot recover the original private values.
