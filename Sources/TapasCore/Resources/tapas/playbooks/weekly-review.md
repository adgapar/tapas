# Review a week

Use when asked for a weekly review or a project update spanning recordings.
Resolve the requested dates and project, find relevant recordings, and read the
source passages rather than relying on index previews. Report gaps in coverage.
Use `templates/project-update.md` unless the user chooses another template.

Synthesize changes across recordings in chronological order. A later plan does
not prove earlier work was completed. Cite sources for decisions and progress;
keep suggestions separate from recorded commitments.

Return the review in the conversation unless asked to save it. Default saved
reviews to a new dated Markdown file under `outputs/` in the current library.
Link to sources relative to that file. This playbook does not schedule itself
or authorize sending the review to anyone.
