# Learn my writing preferences

Use when asked to derive an editable writing guide from saved dictations.
Use the requested period, or the last 30 days if unspecified, and report actual
dates, takes reviewed, and coverage limitations. Read the source takes.

Separate explicit preferences (such as “keep this short”) from inferred patterns
(such as frequently drafting brief messages). Cite examples for each preference.
A request aimed at one recipient or one document is not automatically a global
preference. Keep preferences scoped by language, audience, and task where useful;
show conflicts instead of silently choosing one. Later explicit corrections can
supersede earlier instructions for the same context.

Speech disfluencies, recognition errors, and redaction markers are not writing
preferences. Dictado contains spoken input, not necessarily final writing. Avoid
personality or sensitive-trait conclusions. With sparse evidence, produce a small
provisional guide and identify what remains uncertain.

Return a guide with explicit preferences, tentative patterns, contextual exceptions,
and supporting sources. Include a short reusable instruction block separately
from the evidence. If asked to save, create a new Markdown file under `outputs/`
unless the user names a destination. Apply it to a library template or install it
as persistent agent guidance only when requested; do not change global assistant
instructions merely because the user asked to discover their preferences.
