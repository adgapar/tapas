Tapas — Small tools. Good company.
0.1.0 · Dictado + Acta

Requires an Apple silicon Mac (M1 or newer) running macOS 15 or later.

1. Quit any running copy of Tapas from its menu-bar menu. Finish or discard any
   active recording first.
2. Drag Tapas onto Applications. Choose Replace if an older copy is installed.
3. Eject this disk image, then open Tapas from Applications.
4. Complete setup if this is your first install. Voice models download once.
   Existing settings, models and transcripts are kept.
5. Allow microphone access. Accessibility enables Dictado's global shortcut and
   automatic paste. If an old development copy is still listed, remove its
   Accessibility entry and add the Tapas installed in Applications.

Tapas lives in the menu bar. Open Your plate for Tools, Recent and Preferences.
Dictado: press Control–Option (or your shortcut) to start and finish a take.
Acta: open it from Tools or accept its suggestion when another app uses the mic.
Choose the meeting app and grant Screen & System Audio Recording access when
asked. Start only when everyone is ready to be recorded. Pause stops both inputs.

Tapas checks for updates and downloads them automatically. Updates install when
you quit or choose to restart; active recordings and recovery delay restarting.
Use Your plate → More → Check for Updates, or change update settings in Preferences.
Future updates become available when a new signed release is published.

Dictado's optional redacted history: ~/Documents/tapas/dictado/
Acta's full meeting transcripts: ~/Documents/tapas/acta/
Acta recovery: ~/Library/Application Support/Tapas/ActaRecovery/

Recognition runs on this Mac. Model downloads and SDK usage/licensing reporting
and update checks/downloads use the network. See PRIVACY.md and NOTICE.md for details.

Acta's live-call accuracy, microphone attribution and device changes still need
broader testing. Please report issues at the link below.

Feedback: https://github.com/adgapar/tapas/issues
