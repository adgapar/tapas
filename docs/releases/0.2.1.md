# Tapas 0.2.1

Discover assistant setup after your first practice take.

- **An optional next step:** the onboarding practice result offers to set up Claude Code, Codex or Cursor to find recordings and answer questions about them.
- **Go straight to setup:** choose **Set up assistant** to open the assistant controls in Preferences. Installing the skill remains a separate choice.
- **Come back later:** choose **Maybe later** to finish onboarding. Assistant setup is always available in Preferences.
- **Clearer documentation:** the README lists all 25 supported dictation languages and links to the underlying NVIDIA Parakeet model.

Choose **Check for Updates…** in Tapas, or download the DMG and drag Tapas into Applications.

Requires macOS 15 or later on Apple silicon. Powered by Desert Ant Labs.
