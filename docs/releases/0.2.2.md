# Tapas 0.2.2

Set up your AI assistant without leaving onboarding.

- **Install right here:** choose Claude Code, Codex or Cursor on the final setup step, install the Tapas skill, and see its status on the same page. No detour to Preferences.
- **Practice is optional:** assistant setup is available before or after a practice take, even before downloading voice models. You can finish onboarding without installing a skill.
- **Consistent controls:** onboarding and Preferences share the assistant picker and installation controls. Preferences also provides removal, setup commands and index management.
- **A cleaner home screen:** removed the redundant Dictado options link and the assistant link under Acta. The compact home screen fits without a scrollbar; extra notices and recovery controls can still scroll when needed.

Choose **Check for Updates…** in Tapas, or download the DMG and drag Tapas into Applications.

Requires macOS 15 or later on Apple silicon. Powered by Desert Ant Labs.
