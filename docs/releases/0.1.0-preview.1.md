Tapas’s first installable preview brings **Dictado** to an Apple silicon Mac.
**Small tools. Good company.**

Acta is shown as **In dev** and is not functional yet. This is a prerelease for
testing Dictado; the full product launch still waits for both tools.

### Download and install

Download `Tapas-0.1.0-preview.1-arm64.dmg`, open it, and drag Tapas to Applications.
Quit an older copy first, eject the image, then open the installed app.
Requires **Apple silicon (M1 or newer), macOS 15+**, and internet for initial model
downloads. The models are downloaded during setup, not bundled in the DMG.

This preview is **ad-hoc signed and not notarized**. macOS may block its first
launch. If you trust the download, follow [Apple’s Open Anyway instructions](https://support.apple.com/102445).
Existing development installs may need the installed app re-added to Accessibility.

### Included

- Gráfico onboarding, microphone setup, model preparation and a practice take.
- Local dictation in 25 European languages, custom shortcuts and automatic paste.
- El borde: a tiny four-color recording tab with audio-driven motion, optional
  live captions, hover controls, cancellation and a brief Listo receipt.
- English filler removal on finished takes, using Ear → Voz → Uhm.
- Optional Markdown history with Redact applied to saved copies; pasted words
  are not redacted. Copy, export and independent paste/save retries preserve results.
- Tools, Recent and Preferences in the menu-bar home.

### Preview limits

- Acta is not implemented. Intel Macs are not included in this build.
- There is no LLM rewriting or grammar-polishing pass; filler removal is English only.
- Redaction can misclassify words. Saved history is not a verbatim copy.
- Recovery is held in memory; copy, export or save it before quitting.
- Full-screen, multiple-display, VoiceOver and other receiving-app combinations
  need more testing. There is no automatic updater yet.

Audio and transcripts are processed locally. Model downloads and the SDK’s
usage/licensing reporting use the network; see [privacy details](https://github.com/adgapar/tapas/blob/main/PRIVACY.md).

Validation: 64 automated core tests, native view renders, debug/release builds,
and user-confirmed dictation/shortcut/El borde operation. Packaging checks verify
the app signature, architecture, version, installer contents and DMG integrity.
The adjacent `.sha256` file verifies the download. A fresh-Mac installation has
not yet been tested.
