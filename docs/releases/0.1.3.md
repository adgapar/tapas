# Tapas 0.1.3

Fixes a crash when opening Tapas introduced in 0.1.2. The floating home and setup now handle temporary zero-size layouts safely.

Apple silicon · macOS 15 or later. Existing settings and transcripts are retained.

If 0.1.2 crashes before you can check for updates, download the 0.1.3 DMG and drag Tapas into Applications, replacing the previous copy. Otherwise, choose **Check for Updates…** in Tapas.
