# Tapas 0.1.0 Preview 2 — Acta and automatic updates

This preview adds local meeting transcription alongside Dictado. Acta records
microphone and selected-app audio, writes full Markdown transcripts, and supports
pause/resume and recovery. A local microphone-use suggestion can offer to start
Acta when another app begins using the microphone; no meeting integrations are
required. Recording starts only after you choose to start it.

## Installation and updates

Requires Apple silicon and macOS 15 or later. Download
`Tapas-0.1.0-preview.2-arm64.dmg`, drag Tapas to Applications, eject the image and
open the installed app. The app and installer are Developer ID signed, notarized
by Apple and stapled for Gatekeeper verification.

Sparkle checks for and downloads future published updates automatically.
Preferences includes automatic-update controls; More includes **Check for
Updates…**. Recording and recovery delay restarting. Previous builds require
one manual installation of this preview to gain automatic updates.

## Preview limitations

Live meeting accuracy, microphone attribution and audio-device changes need
broader real-call testing. Acta does not yet provide generated summaries or
speaker diarization. Saved transcripts remain directly accessible Markdown files.
See [privacy details](https://github.com/adgapar/tapas/blob/v0.1.0-preview.2/PRIVACY.md).
